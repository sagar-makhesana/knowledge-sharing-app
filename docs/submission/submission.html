The problem

The answer usually exists. Finding it is the hard part.

Altegra consultants work on the same platforms at many customers: Aras Innovator, Teamcenter, SQL Server, IIS and the integrations around them. So the same problems keep coming back.

What happens today

  • A server Method breaks after an upgrade, an app pool recycles in the middle of the day, a database restore causes a collation conflict. Someone at Altegra has fixed it before.
  • That fix lives in a colleague’s head, an old Teams chat, a customer-specific wiki or a personal notes file. None of these can be searched by symptom.
  • So the consultant either interrupts colleagues or solves it again from scratch, often while the customer waits.
  • When people change projects or leave, their hard-won knowledge leaves with them.

Why existing tools don’t solve it

  • Chat and email are organised by conversation, not by problem.
  • Customer wikis are silos. A fix found at customer A never reaches the team at customer B.
  • Writing documentation feels like admin, so it doesn’t happen unless it takes almost no effort.

Our answer: one place, built around two moments in a consultant’s day

  1. “I’m stuck.” Type the error or symptom and get ranked answers with the matching words highlighted, even with a typo.
  2. “I just fixed it.” Share it in a few minutes with a guided template, Markdown and code blocks, without creating an account.

And we connect the two: a search that finds nothing offers Submit this knowledge, with the title already filled in from the search, so every gap in the knowledge base becomes its next entry.

Innovation

What’s different about it

Search tuned for technical text

Built on MiniSearch, but tuned for how consultants search:

  • Title and tags weigh more than body text.
  • Prefix matching while typing (recycl finds “recycling”).
  • Typo tolerance only on longer words, so lock doesn’t match “look”.
  • Filler words are ignored, so “how to fix the collation” works.
  • All words must match. If nothing does, the app shows partial matches and says so.

We highlight exactly the words the index matched, including tags.

Designed to be used, not just filled in

  • The knowledge loop. Failed searches turn into pre-filled submissions, so the knowledge base grows where people actually need it.
  • Zero-friction sharing. No account, a guided template, and tag suggestions that keep the vocabulary consistent.
  • Shareable searches. Every query, filter and sort is a link.
  • Always current, no search server. The index is rebuilt automatically when the data changes, even across serverless instances.
